# Authentik OIDC for Netbird

Goal: log in to the Netbird dashboard & CLI peers with Authentik accounts.

Netbird is the TrueNAS catalog app **netbird-server** (combined `netbirdio/netbird-server`). That binary **always runs embedded Dex**; chart `additional_envs` cannot replace primary IdP (see [netbird#5335](https://github.com/netbirdio/netbird/issues/5335)).

**Required on TrueNAS chart:** `embedded_idp=true` and `netbird_address=https://{NETBIRD_DOMAIN}/`. Chart then sets dashboard `AUTH_CLIENT_ID=netbird-dashboard` and `AUTH_AUTHORITY=https://{NETBIRD_DOMAIN}/oauth2`. Setting `embedded_idp=false` drops client id → dashboard error `Unauthenticated`.

**Path A (this stack):** keep Dex. In NetBird UI → Identity Providers → add Generic OIDC (see [NetBird Authentik docs](https://docs.netbird.io/selfhosted/identity-providers/authentik)). Then disable local login. Do not expect classic `NETBIRD_AUTH_*` envs to disable Dex on this chart.

Caddy splits dashboard vs gRPC — see [caddy/Caddyfile](../../../caddy/Caddyfile) and [netbird-server/README.md](../../../netbird-server/README.md).

Creds: `instance/netbird-server/.env.oidc` (never print). Create the Authentik app with `.cursor/skills/authentik` scripts (`create-oidc-app.py` / `api.py`). Do not curl.

## In Authentik (`https://{AUTH_DOMAIN}`)

### A. Create OAuth2/OpenID Provider

`Applications > Providers > Create > OAuth2/OpenID Provider`:

- Name: `netbird`
- Authentication flow: `default-authentication-flow`
- Authorization flow: `default-provider-authorization-implicit-consent`
- Client type: `Public` (PKCE)
- Client ID: copy → `NETBIRD_AUTH_CLIENT_ID`
- Client Secret: leave empty (Public)
- Grant types:
  - `authorization_code`
  - `refresh_token`
  - `client_credentials`
  - `password`
  - `urn:ietf:params:oauth:grant-type:device_code`
- Redirect URIs (one per line). TrueNAS chart dashboard uses `/nb-auth` + `/nb-silent-auth`:
  ```
  https://{NETBIRD_DOMAIN}/nb-auth
  https://{NETBIRD_DOMAIN}/nb-silent-auth
  https://{NETBIRD_DOMAIN}/peers
  https://{NETBIRD_DOMAIN}/auth
  https://{NETBIRD_DOMAIN}/silent-auth
  http://localhost:53100
  http://localhost:53000
  ```
  Keep both localhost URIs: Windows clients may still request `:53000` until the NetBird app is restarted; `:53100` is used after restart when `:53000` is in a Windows excluded port range.
- Signing Key: `authentik Self-signed Certificate`
- Subject mode: `Based on the User's ID`
- Include claims in id_token: yes
- Scopes: `email`, `openid`, `profile`, `offline_access`, `goauthentik.io/api`

Save. Issuer URL: `https://{AUTH_DOMAIN}/application/o/netbird/`

### B. Create Application

`Applications > Applications > Create`:
- Name: `Netbird`
- Slug: `netbird`
- Provider: `netbird`

Bind group `netbird` (from `instance/maps/permissions`). Do not bind a user directly

### C. Create API app account (optional — IDP management)

Only if NetBird UI IdP sync must create/update Authentik users.

`Directory > Users > Create app Account`:
- Username: `netbird-svc`
- Create group: yes

Create an app password under `Directory > Tokens and App passwords`.
Copy → `NETBIRD_IDP_MGMT_EXTRA_PASSWORD`. Username → `NETBIRD_IDP_MGMT_EXTRA_USERNAME`.

- Required: add `netbird-svc` to built-in `authentik Admins`.
- Required: bind `netbird-svc` directly to the `Netbird` application (or the same group bound to the app).
- `Can view Users` is not enough (role update/delete fails).
- Do not use `authentik Read-only`.
- Do not use the app-account API token; Netbird needs an app password.

### D. Get OIDC discovery URL

`https://{AUTH_DOMAIN}/application/o/netbird/.well-known/openid-configuration`

Note `authorization_endpoint`, `token_endpoint`, `device_authorization_endpoint`, `jwks_uri`.

## In NetBird UI

Identity Providers → Generic OIDC:

- Issuer: `https://{AUTH_DOMAIN}/application/o/netbird/`
- Client ID: from step A (same string as audience)
- Disable local login after Authentik login works

## Verify

Open `https://{NETBIRD_DOMAIN}` → Authentik login → dashboard with the Authentik user.

## Troubleshoot

Common: `audience mismatch` → audience = literal client_id.
Common: `401 Token invalid` / `unable to get authentik token, statusCode 400` → enable `client_credentials` grant, use an app password, bind `netbird-svc` to the Netbird application.
Common: `Permission denied` / `Policy binding 'None' returned result 'False'` → user is not in a group bound to the Netbird app (or its entitlements). Bind `netbird` (or the user) on the application and on any app entitlements. Authentik → Applications → Netbird → Policy / Group / User Bindings.
