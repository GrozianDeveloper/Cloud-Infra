# Apply Authentik groups map

Source of truth: [`instance/maps/permissions`](../../../instance/maps/permissions/Readme.md) + [`auth_apps`](../../../instance/maps/auth_apps/Readme.md). Index: [`instance/maps/index.md`](../../../instance/maps/index.md).

Apply: `python3 instance/maps/permissions/apply.py`, `python3 instance/maps/auth_apps/apply.py`, `python3 instance/maps/permissions/apply-permissions-map.py`. Do not curl Authentik — `.cursor/skills/authentik` scripts only. Never delete.

## Goal

Authentik groups = who the person is. App login and Nextcloud rights follow from group membership.

- **Nextcloud:** group = application entitlement slug. Bound to the Authentik group of the same row. `user_oidc` maps `entitlements` → NC groups on login.
- **Apps with a real login:** Authentik Application + Group Binding on the instrument group (`cloud`, `gitea`, `netbird`, …). No binding → user cannot launch / FA-deny.
- **Nested groups → apps:** claims include the user’s groups **and every ancestor** (`parents`, then their `parents`, …).
- **n8n user-sync adapters:** optional later. NC groups still arrive on next OIDC login.

Do not grant an app to a user directly — bind a group ([user-managment](../../../.cursor/rules/user-managment.mdc)).

## Effects

| What | Result |
|------|--------|
| Humans in Users Groups | Direct members of listed groups only. Map **Parents** → Authentik `parents` (many) |
| Authentik `path` | Set from path table, **max priority** among direct groups ∪ all ancestors |
| Service accounts | Untouched (`goauthentik.io/services`, outposts) |
| Nextcloud | Groups = entitlement slugs. Collectives / Talk / Deck / Team Folders ACL from the instance map. Users see them after **re-login** |
| WordPress | OIDC login (plugin). Public pages stay public |
| Gitea | OIDC auth source name **must** be `authentik`. Access = Group Binding `gitea` |
| NetBird | Keep **embedded Dex**. Add Authentik as extra IdP. Disable local login. Do **not** set `embedded_idp=false` ([chart breaks](https://github.com/netbirdio/netbird/issues/5335)) |
| n8n | Authentik app + binding only. Native OIDC needs Enterprise license. **No FA** (would break MCP OAuth) |
| NocoDB | Authentik **Proxy FA** + Caddy `authentik_forward_auth` (community has no SSO) |
| Stubs (no TrueNAS app yet) | Authentik Application + Group Binding only |
| Extra HA OS VM | Own OIDC app/provider. Bind the group from the instance map. **No FA** |
| FileFlows / HandBrake / JDownloader | Proxy FA + Group Bindings |

## Model

1. Users from map **Users Groups**, not “everyone → root org group”.
2. Multiple `parents` on each group; users not copied into parents. Apps receive the ancestor **closure**.
3. Instrument groups stay empty of direct humans unless a Users Groups row names them.
4. Nextcloud surfaces (Collective / Talk / Deck / Folder names) come from the instance map. Keep existing folder names when the map uses aliases.

Authentik 2025.12+: `parents` is many ([release](https://docs.goauthentik.io/releases/2025.12/)). Live API has `parents` / `parents_obj` (no singular `parent`).

Skill `create-group.py` still POSTs `parent` (one). Apply script uses POST/PATCH `parents: [pk, …]` via `api.py`.

### Nested groups in app claims

Walk `parents` until the roots. Send that set to every app.

| App | How |
|-----|-----|
| Nextcloud | Entitlements claim = slugs for every group in the closure. Bind each entitlement **once** to its row’s group. Scope mapping must walk ancestors — a direct-name-only fallback is not enough |
| Authentik library / FA | Bind app to the instrument group (`cloud`, `fileflows`, …). Group Binding includes child-group members. Do not add policy `app-access-group-closure` |
| Tandoor | Bind `tandoor-recipes`. Spaces are manual in Tandoor (not OIDC claims) |
| HomeBox | Bind `homebox`. Shared inventory = invite link in HomeBox UI |
| Gramps | Bind `gramps`. One OIDC user = one tree. Role Owner via `OIDC_GROUP_OWNER=gramps` |
| FA header `X-Authentik-Groups` | Must contain ancestor names (custom scope / property mapping if the outpost sends direct groups only) |
| Gitea | `gitea` / `gituser` if `gitea` is in the closure |
| WordPress | `wordpress/admin_panel` in the closure |

Example: user only in `Team/Lead` is not added to `Team`. Token/headers still include `Team` and every ancestor instrument group (`cloud`, …).

If two map rows share one NC slug, one entitlement, bound to **both** groups.

### Bindings

| Target | Bind group(s) |
|--------|----------------|
| Nextcloud **application** | `cloud` |
| Nextcloud **entitlement** `{slug}` | the row’s Authentik group |
| FileFlows / HandBrake / JDownloader / NocoDB | `fileflows` / `handbrake` / `jdownloader` / `nocodb` |
| Tandoor Recipes | `tandoor-recipes` (app) |
| HomeBox | `homebox` (app) |
| Gramps Web | `gramps` (app) |
| Gitea / NetBird / n8n / stubs / Home | `gitea` / `netbird` / `n8n` / map slug / `home` |
| Extra HA OS VM | the group named in the instance map |
| WordPress application | `wordpress/admin_panel` |

Gitea extra: entitlement `gituser` on app `gitea`, bound to group `gitea`.

Nextcloud entitlement `admin` stays bound to `authentik Admins`.

### Nextcloud entitlement names

Row’s first backtick slug. Must be unique (`tech` vs `tech-common`).

`ENTITLEMENT_ATTRS` and role priority live in [`authentik-create-nextcloud_oidc.py`](../../../master-nextcloud-aio/scripts/oidc/authentik-create-nextcloud_oidc.py) — instance values, not this file.

## Users

### Paths

`paths:` in `instance/maps/permissions/map.yaml`. Assign `path` = max priority among direct groups ∪ ancestors. Leave `goauthentik.io/services` and `goauthentik.io/outposts` as-is.

### Membership

Direct groups only (from the instance map). Skip empty rows. Skip `akadmin`, IdP service accounts, agent tokens, outposts.

## Nextcloud surfaces

NC group name = entitlement slug. Circle / Collective team = that group (member unless role= listed).

Collectives / Talk / Deck / Team Folders / Local `external_storage` from `instance/maps/permissions`. ACL: `python3 instance/maps/permissions/apply-permissions-map.py`. Users re-login.

Do not delete extra folders that are not in the map.

## Order

1. Create groups; PATCH `parents` from the map (all Parents, not one).
2. Create NC entitlements; bind entitlements + applications to the row’s group only.
3. Assign Users Groups (direct only) + paths from group closure.
4. Nextcloud / FA / Gitea mappings: emit ancestor groups, not only direct.
5. OIDC apps (WP, Gitea, n8n, NetBird Application, extra HA, stubs) + NocoDB FA.
6. TrueNAS: WP plugin, Gitea auth source (`gitea/scripts/apply-oidc-host.sh`), Caddy FA (`kill -HUP` caddy). NetBird UI: Generic OIDC + disable local login (not automated).
7. Nextcloud ACL scripts. Users re-login.

NAS one-shot (Gitea CLI, WP plugin, NC occ groups/folders, Caddy HUP): `authentik/scripts/host-apply-auth.sh` via Dockge stack `host-apply-auth`.

## Verify

- Authentik library: user sees only bound apps.
- Nextcloud: user whose **closure** includes `cloud` can login; NC groups = entitlements of the whole closure.
- FA apps: user not in group → 403 from Authentik.
- WP / Gitea: “Login with OpenID / authentik”.
- NetBird: Authentik button; Dex still there; no local password form.
- n8n MCP URL still works without Authentik.
