# Dockge

Catalog app. Stacks for Caddy, Nextcloud AIO, Postiz, one-shots.

## Install

- [dockge/README.md](../../dockge/README.md)
- WebUI host port in `instance/dockge/Readme.md`. Host Network=false.
- HostPath: Stacks=`apps/dockge`, Data=`apps/dockge/data`.

```bash
node .cursor/skills/agentskillexchange-skills-dockge-docker-compose-stack-manager/scripts/dockge-start.mjs list
```

`start` / `down` — confirm first. After Authentik: gate Dockge UI (disable built-in auth).
